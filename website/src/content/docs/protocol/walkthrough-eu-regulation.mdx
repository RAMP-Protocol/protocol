---
title: "Walkthrough: EU Regulation (Free vs Value-Added)"
description: "Same legislation available free (EUR-Lex) and paid (Wolters Kluwer annotated), with ELI identifiers, multilingual support, and the ramp-legal-v1 extension profile."
---

> An AI agent needs the EU AI Act (Regulation 2024/1689). The same legislation is available FREE from EUR-Lex (official text) and for $85 from Wolters Kluwer (annotated, consolidated). RAMP enables transparent comparison -- the agent decides whether annotations are worth the price.

## Scenario

| | EUR-Lex (Free) | Wolters Kluwer (Paid) |
|---|---|---|
| **Provider** | EUR-Lex (`eur-lex.europa.eu`) | Wolters Kluwer (`wolterskluwer.com`) |
| **Content** | Official Journal text (original) | Annotated, consolidated with amendments |
| **Price** | FREE | $85 per article |
| **Mutability** | STATIC (original OJ text, never changes) | DYNAMIC (consolidated to latest amendments) |
| **Attestation** | Level 2 (Official Journal = highest legal authority) | Level 1 (self-attested) |
| **Format** | Akoma Ntoso XML | HTML with annotations |

Both scenarios follow the same six-step flow:

```
Discovery -> ResourceQuery -> ResourceResponse -> ExecuteTransaction -> Fetch -> ReportUsage
```

---

## Step 1 -- Discovery

The agent knows the EU AI Act's ELI URI: `http://data.europa.eu/eli/reg/2024/1689/oj`. The Broker resolves both providers' RAMP manifests.

**EUR-Lex:**

```json
// GET https://eur-lex.europa.eu/.well-known/ramp.json
{
  "ver": "1.0",
  "provider": "eur-lex.europa.eu",

    {
      "domain": "exchange.eurlex.europa.eu",

  ],
  "supported_profiles": ["ramp-legal-v1"]
```

**Wolters Kluwer:**

Both Exchanges declare `ramp-legal-v1`, signaling support for legislation-specific `ext` fields (ELI, CELEX, consolidation status, amendment chains).

## Step 2 -- ResourceQuery

The Broker fans out the same query to both Exchanges. The agent identifies the resource by its ELI URI and requests legal-profile metadata:

```json
POST https://exchange.eurlex.europa.eu/ramp/v1/ramp.v1.ExchangeService/DiscoverResources

{
  "ver": "1.0",
  "id": "sq-eli-001",
  "requester": {
    "id": "legal-research-agent",
    "domain": "lawfirm.eu",
    "type": "REQUESTER_TYPE_AGENT",
    "scopes": ["*"],
    "signature": "ed25519:a4c9f2e8b7d1...",
    "signature_algorithm": "ed25519"
  },
  "uris": [
    "http://data.europa.eu/eli/reg/2024/1689/oj"
  ],
  "acceptable_restrictions": [
    { "axis": "FUNCTION", "values": ["ai-input"] }
  ],
  "supported_profiles": ["ramp-legal-v1"],
  "ext": {
    "legal.legislation.language_preference": "en"
  }
}
```

The same `ResourceQuery` (with a different `id`) is sent to `exchange.wk-legal.com`. The `legal.legislation.language_preference` field (from the `ramp-legal-v1` profile) tells both Exchanges to return the English version. EU legislation exists in 24 official languages -- all equally authentic under EU treaty law.

### What the Broker Learns

| Dimension | EUR-Lex | Wolters Kluwer |
|---|---|---|
| **Price** | FREE | $85.00 |
| **Pricing model** | `PRICING_MODEL_FREE` | `PRICING_MODEL_PER_UNIT` |
| **Tokens (est.)** | 89,000 | 111,200 (more due to annotations) |
| **Mutability** | `STATIC` (original OJ text) | `DYNAMIC` (consolidated, updates with amendments) |
| **Attestation** | Level 2 -- `publications.europa.eu` (Publications Office) | Level 1 -- self-attested by `wolterskluwer.com` |
| **Consolidation** | `original` (as published July 2024) | `consolidated_to_2026-01-15` (includes all amendments) |
| **Annotations** | None | 47 cross-references, expert commentary |
| **Training permitted** | Yes (public domain, Decision 2011/833/EU) | No (`ai-train` prohibited) |
| **Format** | Akoma Ntoso XML | HTML |
| **Languages** | 24 (all EU official) | 4 (en, de, fr, nl) |

The agent sees both options with transparent pricing. The free EUR-Lex version carries a **higher attestation level** (Level 2, from the Publications Office of the EU -- the entity that publishes the Official Journal). The Wolters Kluwer version carries a **higher token count** because annotations, cross-references, and consolidation notes add ~22,000 tokens of value-added content.

## Step 4 -- Agent Choice + Transaction

The Broker presents both offers. The agent's choice depends on context:

- **Need the original enacted text?** EUR-Lex. Free, STATIC, Level 2 attested, hash-verifiable.
- **Need the latest consolidated version with expert annotations?** Wolters Kluwer. $85, DYNAMIC, includes 47 cross-references and amendment chain.

Assume the agent chooses EUR-Lex (free). The `ExecuteTransaction` follows the standard pattern:


## Step 5 -- Fetch

The agent fetches via the signed URL:

```
GET https://cdn.eurlex.europa.eu/legal-content/EN/TXT/XML/?uri=CELEX:32024R1689
    &expires=1742404200&agent_id=3e8f1a2b...&txn_id=txn-eurlex-001
    &sig=hmac-sha256-e7f8a9...
```

EUR-Lex delivers the regulation as **Akoma Ntoso XML** -- the OASIS standard for legislative documents. Because `resource_mutability` is `STATIC`, the agent verifies the SHA-256 hash against `identity.content_hash`. A match confirms this is the exact Official Journal text as published on 12 July 2024.

If the agent had chosen the Wolters Kluwer offer instead, the signed URL would point to `cdn.wk-legal.com`. Because `resource_mutability` is `DYNAMIC`, hash verification is informational only -- the consolidated text changes whenever new amendments are incorporated.

## Key Takeaways

### Same Content, Different Value

EU legislation is **public domain** (Decision 2011/833/EU). The raw text is free from EUR-Lex. Wolters Kluwer's $85 price is for the **value-add**: expert annotations, 47 cross-references, and consolidated text that incorporates amendments. RAMP makes this transparent -- the agent compares both offers side by side and decides if the annotations are worth the cost.

### ELI URI as Universal Identifier

The [European Legislation Identifier](http://data.europa.eu/eli) (ELI) provides a stable, machine-readable URI for every EU legal act. Both Exchanges use the same ELI (`http://data.europa.eu/eli/reg/2024/1689/oj`), enabling the Broker to match offers for the same legislation across providers -- even when `canonical_url` differs.

### STATIC vs DYNAMIC for the Same Legislation

The original OJ text is `STATIC` -- it was published once and never changes. The Wolters Kluwer consolidated version is `DYNAMIC` -- it evolves as amendments are incorporated. The `legal.legislation.consolidation_status` ext field tells the agent exactly what version it is getting: `original` vs `consolidated_to_2026-01-15`.

### ramp-legal-v1 Extension Profile

The `ramp-legal-v1` profile provides the vocabulary that makes this walkthrough possible:

| Ext field | Purpose |
|---|---|
| `legal.legislation.eli` | ELI URI for cross-exchange matching |
| `legal.legislation.celex` | CELEX number (EU-internal identifier) |
| `legal.legislation.consolidation_status` | `original`, `consolidated_to_{date}` |
| `legal.legislation.amendment_chain` | Ordered list of ELI URIs showing how the act has been amended |
| `legal.legislation.cross_references` | Count of cross-references to other legislation |
| `legal.legislation.annotations` | Whether expert annotations are included |
| `legal.legislation.language_preference` | Requested language (ResourceQuery ext) |
| `legal.legislation.languages_available` | Available language versions (Offer ext) |

### Attestation Levels Tell the Trust Story

EUR-Lex carries a **Level 2** attestation from `publications.europa.eu` -- the EU's own Publications Office. For legislation, this is the highest possible authority: the entity that publishes the Official Journal is attesting to the content. Wolters Kluwer carries a **Level 1** (self) attestation -- trustworthy as a legal publisher, but not the authoritative source.

### Free Access Still Flows Through RAMP

Even at $0, the full protocol pipeline applies: signed URLs, agent identity binding, usage reporting, and the dispute chain. This creates an audit trail that benefits both sides -- the agent proves it accessed content legitimately, and EUR-Lex gains aggregate usage intelligence.
