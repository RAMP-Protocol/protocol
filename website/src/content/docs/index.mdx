## Key Capabilities

<CardGrid>
  <Card title="Resource Attestation" icon="approve-check">
    Three verification levels (none, self-attested, third-party) let agents verify that delivered content matches what was promised -- cryptographically.
  </Card>
  <Card title="Dispute Resolution" icon="warning">
    Automated dispute handling for delivery failures, content hash mismatches, and token count discrepancies. 100% of routine disputes resolved without human review.
  </Card>
  <Card title="Provider Onboarding" icon="add-document">
    ACME-style domain verification, CDN signing key provisioning, and catalog contributor authorization -- a single CLI command to join the ecosystem.
  </Card>
  <Card title="Multi-Exchange" icon="random">
    No walled gardens. Exchange operators, providers, and third parties operate Exchanges. A Broker compares offers across them.
  </Card>
  <Card title="MCP Server" icon="laptop">
    Zero-SDK resource access. Add the RAMP MCP server to any MCP-capable agent and discover, transact, and dispute resources without custom integration.
  </Card>
</CardGrid>
