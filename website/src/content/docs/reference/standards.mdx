RAMP builds on established standards rather than reinventing them. Every standard below
links to its canonical source — and the same registry links the first mention of each
standard inline throughout the docs, so a reference can never drift between this page
and the prose. To add or repoint a standard, edit the single registry entry in
`website/src/data/standards.mjs`.
